# Pipeline

## 1. Primer pipeline

Executa:

```powershell
Get-Service
```

Ara executa:

```powershell
Get-Service | Sort-Object Name
```

Respon:

1. Quina diferència observes entre les dues sortides?
>La primera ordre mostra els serveis sense un ordre específic, mentre que amb Sort-Object Name els serveis apareixen ordenats alfabèticament pel seu nom.
2. Què fa la part situada abans de `|`?
>La part abans de |, en aquest cas Get-Service, és la que obté la informació dels serveis del sistema.
3. Què fa la part situada després de `|`?
>La part després de |, Sort-Object Name, rep les dades de Get-Service i les ordena segons el camp Name.
4. `Sort-Object` crea els serveis o rep serveis creats per una altra ordre?
>Sort-Object no crea els serveis. Rep els serveis que ha obtingut una altra ordre i els ordena.
5. Quina ordre és la que genera inicialment les dades?
>L'ordre que genera inicialment les dades és Get-Service.

Fes ara la prova:

```powershell
Get-Service | Sort-Object Status
```

Què ha canviat?
>He fet la comanda utilitzant Get-Service per obtenir els serveis i Sort-Object Status per ordenar-los segons el seu estat, en lloc d'ordenar-los pel nom.

Finalment:
>He fet la comanda utilitzant Get-Service per obtenir els serveis i Sort-Object Status -Descending per ordenar-los segons el seu estat en ordre descendent. 

```powershell
Get-Service | Sort-Object Status -Descending
```

Explica amb les teves paraules què ha fet el pipeline.
>El pipeline agafa les dades dels serveis, les passa a Sort-Object i aquest les ordena segons el camp Status.

## 2. El mateix problema sense pipeline

Executa:

```powershell
$serveis = Get-Service
```

Ara:

```powershell
$serveis
```

I després:

```powershell
$serveis | Sort-Object Name
```

Compara-ho amb:

```powershell
Get-Service | Sort-Object Name
```

Respon:

1. Obtenen el mateix resultat?
>Sí, obtenen el mateix resultat. Tant $serveis | Sort-Object Name com Get-Service | Sort-Object Name mostren els serveis ordenats pel seu nom.
2. Quina diferència hi ha entre les dues formes de treballar?
>La diferència és que en el primer cas he guardat primer els serveis dins de la variable $serveis i després he utilitzat aquesta variable. En el segon cas, Get-Service obté els serveis directament i els passa a Sort-Object mitjançant el pipeline.
3. En quin cas s'ha guardat prèviament la informació en una variable?
>La informació s'ha guardat prèviament en una variable en el cas de $serveis = Get-Service.

Crea ara:

```powershell
$serveisOrdenats = Get-Service | Sort-Object Name
```

Mostra:

```powershell
$serveisOrdenats
```

Explica què conté aquesta variable.
>He creat la variable $serveisOrdenats utilitzant Get-Service | Sort-Object Name, de manera que primer he obtingut els serveis i després els he ordenat pel seu nom. La variable $serveisOrdenats conté els serveis del sistema ja ordenats alfabèticament pel camp Name.

## 3. Construir un pipeline pas a pas

Executa primer:

```powershell
Get-Process
```

Ara:

```powershell
Get-Process | Sort-Object CPU
```

Finalment:

```powershell
Get-Process |
    Sort-Object CPU |
    Select-Object -First 5
```

No continuïs fins haver observat el resultat de cada ordre.

Completa:

| Pas | Ordre | Què entra? | Què surt? |
|---|---|---|---|
| 1 | `Get-Process` | | |
| 2 | `Sort-Object CPU` | | |
| 3 | `Select-Object -First 5` | | |

Explica què passaria si eliminéssim:

```powershell
Sort-Object CPU
```

del pipeline.

Comprova-ho executant:

```powershell
Get-Process | Select-Object -First 5
```

Els cinc processos obtinguts són necessàriament els que consumeixen més CPU?

Explica per què.

>Si eliminéssim Sort-Object CPU, el pipeline seria Get-Process | Select-Object -First 5. En aquest cas, Select-Object agafaria directament els primers 5 processos que retorna Get-Process, sense ordenar-los abans.

>He comprovat la comanda Get-Process | Select-Object -First 5 i els cinc processos obtinguts no són necessàriament els que consumeixen més CPU, perquè no s'ha fet cap ordenació per CPU. Simplement s'han seleccionat els cinc primers processos que retorna Get-Process.

## 4. Ordenar processos

Emmagatzema en una variable tots els processos que s'estan executant ordenats de **major a menor consum de CPU**.

Mostra després el contingut de la variable.
>He creat la variable utilitzant Get-Process i Sort-Object CPU -Descending per obtenir tots els processos ordenats de major a menor consum de CPU.

    $processos = Get-Process | Sort-Object CPU -Descending

>He mostrat el contingut de la variable $processos.

    $processos
A partir de la variable anterior:

1. mostra els tres primers processos;
>He utilitzat la variable $processos i Select-Object -First 3 per mostrar els tres primers processos. $processos | Select-Object -First 3

2. mostra els cinc primers;
>He utilitzat la mateixa variable i he seleccionat els cinc primers processos. $processos | Select-Object -First 5

3. mostra els deu primers.
>He utilitzat la mateixa variable i he seleccionat els deu primers processos. $processos | Select-Object -First 10

No tornis a executar `Get-Process` per fer aquests tres apartats.
