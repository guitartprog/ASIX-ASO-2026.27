# `Select-Object` i `Where-Object`

> **Nota:** Els exercicis t'han de servir per familiaritzar-te amb PowerShell. No et limitis a executar les ordres: fes proves, modifica valors i propietats i observa què passa. Documenta les proves que consideris rellevants.
## 1. Investigar els objectes

Executa:
```
Get-Process
```
Observa la informació que mostra PowerShell.

Ara investiga un procés amb:

```
Get-Process |
    Select-Object -First 1 |
    Select-Object *
```
i:
```
Get-Process |
    Get-Member
```
Respon:

1. `Get-Process` mostra inicialment totes les propietats de l'objecte?
>No. Per defecte, PowerShell mostra una selecció de propietats en format de taula per facilitar-ne la lectura. Amb Select-Object * podem consultar totes les propietats disponibles de l'objecte seleccionat.

2. Quina diferència hi ha entre `Select-Object *` i `Get-Member`?
>- Select-Object * mostra els valors de totes les propietats de l'objecte. - Get-Member mostra els membres de l'objecte, com ara les propietats i els mètodes, i indica els seus tipus. Per tant, Select-Object * serveix per consultar les dades d'un objecte, mentre que Get-Member serveix per investigar-ne l'estructura.
  3. Localitza almenys tres propietats que no coneixies. 
  >Algunes propietats interessants de Get-Process són: Path: indica la ruta de l'executable del procés, quan està disponible. StartTime: indica la data i l'hora en què s'ha iniciat el procés, quan es pot consultar. Handles: indica el nombre de controladors de recursos del sistema que utilitza el procés.

    
Utilitza després `Select-Object` per mostrar únicament tres propietats que consideris útils.
## 2. Seleccionar propietats i objectes

Amb `Get-Process`, construeix ordres que permetin:

1. mostrar només `Name` i `CPU`;
>Get-Process | Select-Object Name, CPU
    
2. mostrar només `Name`, `Id` i `CPU`;
>Get-Process | Select-Object Name, Id, CPU

3. mostrar només els cinc primers processos;
 >Get-Process | Select-Object -First 5

4. mostrar només els tres últims processos.
>Get-Process | Select-Object -Last 3    

Respon:

**Quina diferència hi ha entre seleccionar propietats i seleccionar objectes?**
>Seleccionar propietats significa triar quines dades volem mostrar de cada objecte. Per exemple, Select-Object Name, CPU mostra només el nom i el consum de CPU de cada procés.

>Seleccionar objectes significa triar quins elements volem obtenir d'una col·lecció. Per exemple, Select-Object -First 5 retorna els cinc primers processos.


## 3. Ordenar i seleccionar

Construeix un pipeline que mostri els **cinc processos amb més CPU**.

La sortida ha de mostrar únicament:

```
Name
Id
CPU
```

Compara després aquestes dues estratègies:

```
ordenar → seleccionar 5
```

i:

```
seleccionar 5 → ordenar
```

Respon:

1. Fan el mateix?
>No. La primera estratègia mostra els cinc processos amb més CPU. La segona només ordena els cinc processos que s'han seleccionat inicialment, que no necessàriament són els que més CPU utilitzen.
    
2. Per què?
>Perquè l'ordre de les operacions del pipeline és important. A la primera estratègia, s'ordenen tots els processos abans de seleccionar-ne els cinc primers. A la segona, primer es descarten tots els processos excepte els cinc primers i només després s'ordenen els que queden.
    
3. Quants processos rep `Sort-Object` en cada cas?

>- Estratègia A: rep tots els processos retornats per Get-Process.
>- Estratègia B: rep només els cinc processos seleccionats per Select-Object -First 5.
    
>Conclusió: si volem obtenir els cinc processos amb més CPU, primer hem d'ordenar tots els processos de manera descendent i després seleccionar-ne els cinc primers.


    
## 4. Primer filtre

Crea:

```
$numeros = 5, 20, 3, 40, 12, 8, 30
```
>$numeros = 5, 20, 3, 40, 12, 8, 30
Utilitzant `Where-Object`, mostra (adjunta comandes):

1. els números superiors a `10`;
>$numeros | Where-Object { $_ -gt 10 }
    
2. els números inferiors a `20`;
>$numeros | Where-Object { $_ -lt 20 }
    
3. els números iguals a `12`;
>$numeros | Where-Object { $_ -eq 12 }
    
4. tots els números diferents de `20`.
>$numeros | Where-Object { $_ -ne 20 }
    
Per cada cas identifica quin operador has utilitzat:

```
-eq  ES IGUAL A 
-ne ES DIFERENT A 
-gt MES GRAN QUE
-lt MES PETIT QUE 
-ge MES GRAN O = QUE 
-le MES PETIT O = QUE
```


## 5. Entendre `$_`

Utilitza:

```
$numeros = 5, 20, 3
```

i analitza:

```
$numeros |
    Where-Object { $_ -gt 10 }
```

Completa:

|Valor de `$_`|Resultat de `$_ -gt 10`|Passa el filtre?|
|---|---|---|
|5|5 -gt 10 False|NO|
|20|20 -gt 10 True |SI|
|3| 3 -gt 10 False|NO|

Explica amb les teves paraules:

**Què representa** `$_`**?**
>$_ representa l'element actual que PowerShell està processant dins del filtre Where-Object.
>En aquest exemple, primer representa el número 5, després el 20 i finalment el 3. PowerShell comprova cada número amb la condició -gt 10 i només mostra els que la compleixen.

## 6. Filtrar objectes per propietats

Executa:

```
Get-Service
```

Construeix un pipeline que mostri únicament els serveis que estan en execució.



La sortida final ha de mostrar només:

```
Name
Status
>Get-Service | Where-Object {$_.Status -eq "Running"} | Select-Object Name, Status


```

Després construeix-ne un altre que mostri els serveis que **no** estan en execució.

>Get-Service | Where-Object {$_.Status -ne "Running"} | Select-Object Name, Status

Respon:

1. Què representa `$_`?
>Representa l'objecte actual que s'està processant dins del pipeline. En aquest cas, és un servei concret.
    
2. Què representa `$_.Status`?
>Representa la propietat Status de l'objecte actual, és a dir, l'estat del servei, com ara Running (en execució) o Stopped (aturat).
    
3. Què fa `Where-Object` amb els objectes que no compleixen la condició?
>Els descarta de la sortida del filtre. Només passen al següent element del pipeline els objectes que compleixen la condició.
    
4. Què fa després `Select-Object`?
>Selecciona les propietats que volem mostrar. En aquest exercici, només mostra Name (nom del servei) i Status (estat del servei), descartant les altres propietats de la visualització.

## 7. Combinar condicions

Crea:

```
$numeros = 1, 5, 10, 15, 20, 25, 30, 40
```
>$numeros = 1, 5, 10, 15, 20, 25, 30, 40

Construeix filtres que mostrin:

1. números entre `10` i `30` ambdós inclosos;
>$numeros | Where-Object {$_ -ge 10 -and $_ -le 30}
    
2. números inferiors a `10` o superiors a `30`.
>$numeros | Where-Object {$_ -lt 10 -or $_ -gt 30}

## 8. Pipeline complet

Construeix progressivament un pipeline que:

1. obtingui tots els processos;
>Get-Process
    
2. deixi només els processos amb `CPU > 5`;
>Get-Process | Where-Object {$_.CPU -gt 5}
    
3. deixi, a més, només els processos amb `Id > 1000`;
>Get-Process | Where-Object {$_.CPU -gt 5} | Where-Object {$_.Id -gt 1000}
    
4. els ordeni de major a menor CPU;
>Get-Process | Where-Object {$_.CPU -gt 5} | Where-Object {$_.Id -gt 1000} | Sort-Object CPU -Descending
    
5. mostri només els cinc primers;
>Get-Process | Where-Object {$_.CPU -gt 5} | Where-Object {$_.Id -gt 1000} | Sort-Object CPU -Descending | Select-Object -First 5
    
6. mostri només les propietats:
```
Name
Id
CPU
```
>

No intentis escriure directament tota l'ordre.

Executa-la després d'afegir cada nova etapa i observa com va canviant el resultat.

Representa finalment el recorregut:

```
Get-Process
     ↓
____________
> Where-Object {$_.CPU -gt 5}
     ↓
____________
>Where-Object {$_.Id -gt 1000}  
     ↓
____________
>Sort-Object CPU -Descending
     ↓
     > Select-Object -First 5 |
____________
> Select-Object Name, Id, CPU
```

Indica què entra i què surt de cada etapa.
>Get-Process	Cap objecte d'entrada	Tots els processos

>Where-Object {$_.CPU -gt 5}	Tots els processos	Processos amb CPU superior a 5

>Where-Object {$_.Id -gt 1000}	Processos del filtre anterior	Processos amb ID superior a 1000

>Sort-Object CPU -Descending	Processos filtrats	Processos ordenats per CPU descendent

>Select-Object -First 5	Processos ordenats	Els cinc primers processos

>Select-Object Name, Id, CPU	Els processos seleccionats	Només les tres propietats demanades
