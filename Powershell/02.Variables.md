## 5. Cometes

Executa:

```
$servidor = "SRV01"
```

Després:

```
Write-Host "Servidor: $servidor"
```

i:

```
Write-Host 'Servidor: $servidor'
```
![Descripción de la imagen](/Powershell/img/2.5.png)

Respon:

**Quina diferència observes? Per què creus que passa?**

Les cometes dobles (" ") permeten que PowerShell interpreti les variables que apareixen dins del text.

    "Servidor: $servidor"

Es transforma en:

    Servidor: SRV01

Les cometes simples (' ') tracten el contingut pràcticament de manera literal:

    'Servidor: $servidor'

Per això obtenim:

    Servidor: $servidor

Conclusió: per incloure el valor d'una variable dins d'un text, normalment utilitzarem cometes dobles.

## 6. Guardar el resultat d'una ordre

Executa:

```
$serveis = Get-Service
```

Després:

```
$serveis
```
![Descripción de la imagen](/Powershell/img/2.6.png)


Respon:

- Què creus que conté $serveis?
- La variable conté un únic valor o diversos elements?

La variable $serveis conté els objectes retornats per Get-Service.

No és simplement un text: PowerShell treballa amb objectes.

Com que hi ha molts serveis, la variable conté diversos elements.


Fes el mateix amb:

```
$processos = Get-Process
```

i comprova el seu contingut.

![Descripción de la imagen](/Powershell/img/2.6.2.png)

## 7. Aplicació a administració

Crea una variable:

```
$nomServei = "Spooler"
```

Utilitza aquesta variable per consultar el servei amb:

```
Get-Service -Name ...
```

L'objectiu és obtenir el mateix resultat que:

```
Get-Service -Name Spooler
```

però **sense escriure `Spooler` directament en el cmdlet**.
