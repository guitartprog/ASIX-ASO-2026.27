# Treballar amb fitxers i carpetes

**Situació:** encara no hem estudiat les ordres de PowerShell per treballar amb fitxers i carpetes. Les haurem de descobrir utilitzant les eines d'ajuda de PowerShell.

**1. Buscar ordres**

Busca cmdlets que continguin la paraula `Item`:

```
Get-Command *Item*
```

Observa les ordres que apareixen.

Intenta identificar quina ordre podria servir per:

- crear un element; **New-Item**
- eliminar un element; **Remove-Item**
- canviar el nom d'un element; **Rename-Item**
- copiar un element; **Copy-Item**
- moure un element. **Move-Item**



---

**2. Investigar una ordre**

Sense executar-la encara, consulta què fa:

```
Get-Help New-Item
```

Respon:

- Per a què serveix `New-Item`?
New-Item permet crear elements nous, com ara carpetes, fitxers i altres tipus d'elements compatibles amb PowerShell.

- Quina estructura té l'ordre?

Una sintaxi habitual és:

    New-Item -Path "ruta" -ItemType tipus -Name "nom"

**-Path:** indica la ubicació on es crearà l'element.

**-ItemType:** indica el tipus d'element que volem crear.

**-Name:** indica el nom de l'element.

---


Consulta alguns exemples:

```
Get-Help New-Item -Examples
```

---

**3. Descobrir un paràmetre**

Consulta què significa el paràmetre `-ItemType`:

Aquest paràmetre permet especificar quin tipus d'element volem crear.

```
Get-Help New-Item -Parameter ItemType
```

A partir de l'ajuda, intenta descobrir com crear una carpeta.

Per exemple, haurien d'arribar a alguna cosa semblant a:

```
New-Item -ItemType Directory -Name Prova
```
Per crear una carpeta anomenada Prova:

New-Item -ItemType Directory -Name Prova

També podem indicar la ruta:

New-Item -Path "C:\Prova" -ItemType Directory

---

**4./5 Nou repte**

Ara necessites saber com **canviar el nom de la carpeta**, però no coneixes l'ordre.

Utilitza:

```
Get-Command *Item*
```

i després consulta l'ajuda de l'ordre que creguis adequada.

L'objectiu és arribar a descobrir:

```
Rename-Item
```

i consultar:

```
Get-Help Rename-Item -Examples
```

---

Sense utilitzar Internet, descobreix quins cmdlets faries servir per:

1. crear una carpeta; **New-Item** New-Item -ItemType Directory -Name Prova
2. canviar-li el nom; **Rename-Item** Rename-Item -Path .\Prova -NewName ProvaNova
3. copiar-la; **Copy-Item** Copy-Item -Path .\ProvaNova -Destination .\CopiaProva -Recurse
4. moure-la; **Move-Item** Move-Item -Path .\ProvaNova -Destination .\Destinacio
5. eliminar-la. **Remove-Item** Remove-Item -Path .\CopiaProva -Recurse

**Condició:** només pots utilitzar `Get-Command` i `Get-Help` per investigar les ordres.

Descobrir ordres de xarxa amb PowerShell

## Situació

Estàs administrant un servidor Windows i necessites consultar informació de la seva configuració de xarxa.

Encara no coneixes les ordres de PowerShell relacionades amb xarxa.

La teva feina és descobrir-les utilitzant principalment:

```
Get-Command
Get-Help
```

No pots buscar les respostes a Internet.

---

## Tasques

Descobreix quines ordres de PowerShell et permeten obtenir la informació següent:

1. Mostrar els adaptadors de xarxa de l’equip.      
2. Consultar les adreces IP configurades.      
3. Consultar la configuració IP completa dels adaptadors de xarxa.      
4. Consultar els servidors DNS configurats.      
5. Comprovar si hi ha connectivitat amb un altre equip de la xarxa.  

---
## Per cada tasca

Indica:

- el cmdlet que has trobat;      
- com l’has localitzat amb `Get-Command`;  
- una breu explicació del que fa;  
- la comanda que has executat;  
- el resultat obtingut.  

L'objectiu és que hi hagi una traçabilitat de com s'ha arribat a la comanda final.

 ---

##1.Mostrar els adaptadors de xarxa
**Cmdlet trobat:** Get-NetAdapter

Pas 1. Localitzar l'ordre

    Get-Command *NetAdapter*

També podem fer una cerca més general:

    Get-Command *Adapter*

Pas 2. Consultar l'ajuda

    Get-Help Get-NetAdapter

Pas 3. Executar la comanda

    Get-NetAdapter

**Què fa?** Mostra els adaptadors de xarxa de l'equip, com ara les targetes Ethernet i Wi-Fi, juntament amb informació com el nom, l'estat i la velocitat de connexió.

----
2.Consultar les adreces IP configurades
Cmdlet trobat: Get-NetIPAddress

Pas 1. Localitzar l'ordre

    Get-Command *NetIPAddress*

Pas 2. Consultar l'ajuda

    Get-Help Get-NetIPAddress

Pas 3. Executar la comanda

    Get-NetIPAddress

Per veure només les adreces IPv4:

    Get-NetIPAddress -AddressFamily IPv4

**Què fa?** Mostra les adreces IP assignades a les interfícies de xarxa, tant IPv4 com IPv6 si no filtrem el resultat.

----
3. Consultar la configuració IP completa
Cmdlet trobat: Get-NetIPConfiguration

Pas 1. Localitzar l'ordre

    Get-Command *NetIP*

Una cerca mées específica també és possible:

    Get-Command *NetIPConfiguration*

Pas 2. Consultar l'ajuda

    Get-Help Get-NetIPConfiguration

Pas 3. Executar la comanda

    Get-NetIPConfiguration

**Què fa?** Mostra un resum de la configuració IP de les interfícies de xarxa, incloent-hi les adreces IP, les portes d'enllaç i informació dels servidors DNS.

----
4.Consultar els servidors DNS configurats
Cmdlet trobat: Get-DnsClientServerAddress

Pas 1. Localitzar l'ordre

    Get-Command *Dns*

Pas 2. Consultar l'ajuda

    Get-Help Get-DnsClientServerAddress

Pas 3. Executar la comanda

    Get-DnsClientServerAddress

Per consultar només els servidors DNS IPv4:

    Get-DnsClientServerAddress -AddressFamily IPv4

**Què fa?** Mostra les adreces dels servidors DNS configurats per a cada interfície de xarxa.

---
5. Comprovar la connectivitat amb un altre equip
Cmdlet trobat: Test-Connection

Pas 1. Localitzar l'ordre

    Get-Command *Connection*

També podem cercar:

    Get-Command *Net*

Pas 2. Consultar l'ajuda

    Get-Help Test-Connection

Pas 3. Executar la comanda

Per comprovar la connectivitat amb la porta d'enllaç de l'exemple anterior:

    Test-Connection 192.168.1.1


**Què fa?** Envia peticions de prova ICMP a un equip remot per comprovar si respon.
