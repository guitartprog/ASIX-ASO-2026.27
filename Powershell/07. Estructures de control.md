# Pràctica

## 1. Condicional

Crea:
```powershell
$port = 443
```
Mostra:
```
Port HTTPS
```
si el port és `443`.

Canvia després el valor de `$port` i comprova què passa.

    $port = 443

    if ($port -eq 443) {
        Write-Output "Port HTTPS"
    }

>He executat les comandes de PowerShell amb els ports 443 i 80. Amb el port 443 s'ha mostrat el missatge Port HTTPS, mentre que amb el port 80 no s'ha mostrat cap missatge.

## 2. if o switch

Crea:
```
$estat = 2
```
Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions.

>Solució amb IF:

    $estat = 2

    if ($estat -eq 1) {
        Write-Output "Iniciant"
    }
    elseif ($estat -eq 2) {
        Write-Output "Executant"
    }
    elseif ($estat -eq 3) {
        Write-Output "Finalitzat"
    }
    elseif ($estat -eq 4) {
        Write-Output "En espera"
    }
    else {
        Write-Output "Estat desconegut"
    }


>Solució amb Switch:

    $estat = 2

    switch ($estat) {
        1 { Write-Output "Iniciant" }
        2 { Write-Output "Executant" }
        3 { Write-Output "Finalitzat" }
        4 { Write-Output "En espera" }
        default { Write-Output "Estat desconegut" }
    }

> Comparació - if: permet comprovar condicions diferents; és útil per a lògica complexa. - switch: compara un valor amb diverses opcions; és més clar i ordenat en aquest cas.

## 4. Condicions combinades

Crea:

```powershell
$port = 443
$actiu = $true
```
Mostra:

```text
Servei disponible
```

només quan el port sigui el 443 i estigui actiu

>Codi:

    $port = 443
    $actiu = $true

    if ($port -eq 443 -and $actiu -eq $true) {
        Write-Output "Servei disponible"
}

>Resultat: Servei Disponible

>He executat les comandes de PowerShell amb el port 443 i el servei actiu ($true). S'ha mostrat el missatge Servei disponible perquè es compleixen les dues condicions.

## 7. Objectes

Quants serveis en el teu sistema estan configurats amb el servei d'arrencada automàtic quan s'inicia l'equip? 

Proposa diferents codis de resolució.

>Proposta 1 Amb Get Service:

    Get-CimInstance Win32_Service |
    Where-Object {$_.StartMode -eq "Auto"} |
    Measure-Object

>86

>Proposta 2 mostrant nomes el nombre

    (Get-CimInstance Win32_Service |
    Where-Object {$_.StartMode -eq "Auto"}).Count

>86

>Proposta 3 mostrant els serveis i el total

    $serveis = Get-CimInstance Win32_Service |
    Where-Object {$_.StartMode -eq "Auto"}

    $serveis | Select-Object Name, DisplayName, StartMode
    Write-Output "Total de serveis automàtics: $($serveis.Count)"
