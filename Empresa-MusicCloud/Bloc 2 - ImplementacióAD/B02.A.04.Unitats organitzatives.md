# Enunciat

## Objectiu

Crear l’estructura inicial d’unitats organitzatives del domini `musiccloud.local`.
## Escenari

MusicCloud ja disposa del domini:
```text
musiccloud.local
```
El servidor `SRV-AD-01` ja és controlador de domini.

Ara cal crear una estructura d’unitats organitzatives que permeti organitzar els objectes de l’empresa.
## Estructura que cal crear

Creeu l’estructura següent:
```text
musiccloud.local
└── MusicCloud
    ├── Usuaris
    │   ├── Administracio
    │   ├── Comercial
    │   ├── Desenvolupament
    │   ├── Sistemes
    │   └── Direccio
    ├── Equips
    │   ├── Clients
    │   └── Servidors
    └── Grups
```
## Part 1. Creació de la UO principal

Creeu una unitat organitzativa principal anomenada:
```text
MusicCloud
```
Aquesta UO serà el contenidor principal de l’estructura de l’empresa.

>He creat la UO Principal amb les seguents líneas

>Import-Module ActiveDirectory

## Part 6. Preguntes

Responeu breument:

1. Per què és útil crear una UO principal anomenada `MusicCloud`? 
>Perquè permet tenir tots els objectes de l'empresa organitzats dins d'una mateixa estructura i facilita la seva administració.

2. Per què se separen `Usuaris`, `Equips` i `Grups`?  
>Perquè cada tipus d'objecte té una funció diferent i així és més fàcil trobar-los i administrar-los.

3. Per què els departaments s’han creat dins de `Usuaris`?  
>Perquè permet organitzar els comptes dels treballadors segons el departament al qual pertanyen.

4. Per què no és recomanable deixar tots els usuaris dins del contenidor `Users`?  
>Perquè seria més difícil organitzar-los i administrar-los. Amb les UO podem separar els usuaris per departaments i aplicar configuracions de manera més ordenada.

- 7.1. Crea un script per eliminar totes les OUs creades en la pràctica

>Script (Tambe Adjuntat a la capreta B01.A.04 Scripts):
Import-Module ActiveDirectory

$base = "OU=MusicCloud,DC=musiccloud,DC=local"

$ous = Get-ADOrganizationalUnit -SearchBase $base -SearchScope Subtree -Filter *

$ous | Sort-Object { $_.DistinguishedName.Length } -Descending | ForEach-Object {
    Set-ADOrganizationalUnit -Identity $_ -ProtectedFromAccidentalDeletion $false
    Remove-ADOrganizationalUnit -Identity $_ -Confirm:$false
}

- 7.4. Crea un script que creï l'OU principal si no existeix i que creï únicament les UO descendents que encara no existeixin. El script s'ha de poder executar més d'una vegada sense generar errors ni duplicar objectes.

>Script (Tambe Adjuntat a la capreta B01.A.04 Scripts):

Import-Module ActiveDirectory


$domini = "DC=musiccloud,DC=local"


if (-not (Get-ADOrganizationalUnit -Filter "Name -eq 'MusicCloud'")) {
    New-ADOrganizationalUnit -Name "MusicCloud" -Path $domini
}


$principal = "OU=MusicCloud,$domini"


if (-not (Get-ADOrganizationalUnit -Filter "Name -eq 'Usuaris'" -SearchBase $principal)) {
    New-ADOrganizationalUnit -Name "Usuaris" -Path $principal
}


if (-not (Get-ADOrganizationalUnit -Filter "Name -eq 'Equips'" -SearchBase $principal)) {
    New-ADOrganizationalUnit -Name "Equips" -Path $principal
}


if (-not (Get-ADOrganizationalUnit -Filter "Name -eq 'Grups'" -SearchBase $principal)) {
    New-ADOrganizationalUnit -Name "Grups" -Path $principal
